รายละเอียดโปรเจกต์ (Project Overview)

บทคัดย่อ (Abstract)

ระบบเช็คชื่อเข้าเรียนอัจฉริยะ (Smart Class Attendance) เป็นระบบที่ผสานการทำงานของฮาร์ดแวร์ IoT เข้ากับ Web Application แบบ Real-time เพื่อลดภาระการเช็คชื่อแบบแมนนวล ระบบสามารถระบุตัวตนผ่านบัตร RFID พร้อมวัดอุณหภูมิร่างกายเบื้องต้น และส่งข้อมูลผ่านโปรโตคอล MQTT มายังหน้า Dashboard ทันที

วัตถุประสงค์ (Objective)

  • พัฒนาระบบเช็คชื่ออัตโนมัติที่รวดเร็วและแม่นยำ
  • คัดกรองสุขภาพเบื้องต้นด้วยการวัดอุณหภูมิร่วมกับการเช็คชื่อ
  • แสดงผลข้อมูลแบบ Real-time ให้ผู้สอนและสรุปผลเป็นไฟล์ CSV ได้

คุณสมบัติเด่น (Features)

  • Real-time Dashboard: รับข้อมูลทันทีที่นักศึกษาแตะบัตรผ่าน Secure WebSocket
  • Auto Status: ประเมินสถานะ "ตรงเวลา" หรือ "มาสาย" อัตโนมัติจากเวลาที่ตั้งไว้
  • Health Alert: แจ้งเตือนด้วยสีแดงหากอุณหภูมิร่างกายสูงกว่า 37.5°C

อุปกรณ์และเครื่องมือที่ใช้ (Tools & Hardware)

Arduino Uno R4 WiFi RFID RC522 Thermistor Sensor LED Status MQTT (HiveMQ) Tailwind CSS
